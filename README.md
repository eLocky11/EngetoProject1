# Engeto Academy - Projekt 1: Responsivní webová stránka

Toto je můj první kompletní projekt vytvořený jako úkol pro Front-end Developer Akademie. Projekt představuje responzivní webovou stránku cestovního průvodce, která obsahuje informace o cestování, nabízených zájezdech a reference spokojených klientů.

## Popis projektu

**Your Travel Assistant** je statická webová stránka vytvořená pomocí HTML5 a CSS3, která demonstruje základní principy moderního webového designu a responzivního layoutu. Stránka obsahuje následující sekce:
- **About Us** – stručný popis firmy a autorů projektu.
- **What We Do** – informace o službách a nabízených zájezdech.
- **Our Trips** – galerie s ukázkami cest.
- **Where to go** – sekce s nápady a tipy na destinace.
- **Reviews** – recenze klientů.
- **Gallery** – fotogalerie.

Projekt využívá moderní techniky jako Flexbox, CSS Grid, adaptivní media queries a hladké rolování (smooth scrolling).

## Jak spustit

Jelikož se jedná o statickou stránku, stačí otevřít soubor `index.html` ve vašem webovém prohlížeči. Pro pohodlnější vývoj a testování doporučuji používat lokální server (např. rozšíření Live Server pro VS Code).

## Použité technologie

- **HTML5** – semantická struktura a přístupnost.
- **CSS3** – styling, Flexbox, Grid, media queries.
- **Základní principy responzivního designu**.
